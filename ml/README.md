# `ml` — Training and Evaluation

Model training, dataset adapters, evaluation harness, weights. **Owner: SAR/ML lead.**

```
configs/      training configs, versioned
datasets/     adapters — one per public dataset
training/     train loops, loss functions, augmentation
evaluation/   metrics, ablations, figure generation
notebooks/    exploration only, never the source of a reported number
weights/      checkpoints (git-ignored, hashes recorded in model cards)
```

## Dataset adapters enforce GSD

Every adapter resamples to **40 m/px on load** and **refuses to yield a sample whose GSD it cannot verify**.

Public datasets are built at different resolutions. Mixing them fails silently — healthy loss curve, collapsed field performance, misdiagnosed as domain shift. [ADR 0002](../docs/adr/0002-fixed-ground-sample-distance.md).

## Loss

Focal + Dice, plus a **boundary-gradient term** — 2025–26 work identifies edge prominence as a primary oil-vs-look-alike discriminator. Oil is often under 1% of pixels; class imbalance is severe.

## Augmentation

Flips, 90-degree rotations, multiplicative speckle, sigma-0 level shift (±2 dB, simulating different wind), incidence-angle gradient.

**Never colour jitter or elastic deformation.** Physically meaningless for SAR, and a reviewer who spots them will conclude the team does not understand the sensor.

## Evaluation discipline

| Rule | Why |
|---|---|
| **Test split touched once** | Repeated checking overfits a test set invisibly |
| Fixed seeds, logged | Reproducibility |
| **Three seeds minimum** for headline numbers | A single run is an anecdote |
| Report the cross-domain drop | Expect 10–20 points. Hiding it is worse than having it |
| **Figures generated by script** | Hand-made charts drift from the data they claim to show |

`make evaluate` regenerates every metric and figure into `evaluation/results/`.
